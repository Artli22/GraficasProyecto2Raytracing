# Proyecto No. 2: Gráficas por Computador — Ray Tracing

Proyecto de renderizado de un diorama mediante la técnica de **ray tracing**, con distintos materiales y controles de cámara para explorar la escena.

## Características implementadas

- Escena con múltiples elementos y una composición visual detallada.
- Rotación del diorama.
- Controles para acercar y alejar la cámara.
- Implementación de diferentes materiales.
- Refracción en al menos un material, acorde con su función dentro de la escena.
- Reflexión en al menos un material.
